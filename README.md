# MOCSE — Master of Command 中文存档修改器

当前版本 v0.2.0。仅支持 `SaveGameVersion = 10` 的战役 `.fcs` 存档，拒绝旧版及未验证的未来版本，不提供版本转换。

## 许可

本项目采用 [MIT 许可证](LICENSE)。游戏及其资源的权利归各自权利人所有，不属于本项目的许可范围。

## 启动

双击 `release\MOCSE.exe`，或项目根目录的 `启动修改器.cmd`。
Windows 10/11，需安装 .NET 8 Desktop Runtime；当前开发机器已具备运行环境。分发时请保留整个 release 文件夹，不能只拷贝 EXE。

## 功能

- 资源：资金、粮食、弹药、人力储备。
- 部队：当前兵力、目标兵力、基础兵力上限、当前经验，并显示兵种中英文名称；覆盖现役编队、预备队、将军卫队。
- 军官：现役及预备军官的可用技能点。
- 物品：营地及部队装备槽的数量修改，显示物品中英文名称。
- 新增物品：卡片式列表，支持步兵／炮兵／骑兵筛选与中英文、ID 搜索；优先复用空库存槽，不足时追加，可连续添加多件。
- 保存、另存为、撤销全部未保存修改、源文件变化检测、自动备份。
- 快捷键：Ctrl+O 打开，Ctrl+S 保存，Ctrl+Shift+S 另存。

## 使用

1. 退出游戏，打开版本 10 的 `.fcs` 文件。
2. 自动检测本机常见安装目录。若物品目录未加载，点击「游戏数据目录…」，选择游戏安装目录、StreamingAssets 或 GameData。
3. 在资源页或绿色数值单元格编辑。新增物品位于物品页。独立装备要添加多件时，在新增窗口连续点击「添加」即可；每件默认数量 1，也可稍后在物品表格中修改。
4. 建议首次使用「另存为」。在游戏中选择相应的本地存档；本工具不调用 Steam 云存档 API。

经验值是当前等级内经验，不是累计经验；第一版不自动换算或修改等级。兵力同时受目标兵力和运行时修正影响，目标低于当前值可能触发游戏裁员。游戏可以进一步规范化输入值。

物品与兵种目录在运行时只读游戏 JSON（Items、Units）及 Chinese.json、English.json 语言包，未打包游戏 DLL 或完整资源。现有未知／模组物品保持原样；新增仅允许选取已加载目录中的 ID。首版不解析 DLC 资源包或执行模组脚本，因此不会自动枚举只存在于这些包或脚本中的物品。

## 备份与恢复

每次写入前，会把源文件的完整原始字节备份到源存档旁 `_MOCSE_Backups`。另存覆盖既有目标时，也会备份目标。备份包含时间及随机后缀，不覆盖以前的备份；备份失败则不写存档。

恢复：关闭游戏，把所需 `.bak` 复制到 Campaigns 目录，重命名为 `.fcs`，然后在游戏中读取。保留原备份。

写入采用同目录临时文件、刷新到磁盘、再替换目标。源文件自打开后被其他程序改变或删除时拒绝保存。另存会更新存档内部名称；铁人存档会同步更新其自动保存文件名。保持原存档版本及其余未知字段、`$type`、数组空位、区域、地图迷雾数据。

## 开发与验证

- `src/Mocse.Core`：JSON DOM 编辑、物品目录、备份与文件写入。
- `src/Mocse.App`：中文 Windows Forms 界面。
- `tests/Mocse.Tests`：不依赖测试框架的集成测试可执行程序。
- `artifacts/tests`：版本 10 的合成测试夹具及读写结果。
- `artifacts/ui`：真实 WinForms 控件操作测试与截图。
- `build.ps1`：编译、测试、发布。

构建要求 .NET 8 或更高 SDK，目标为 net8.0 / net8.0-windows；没有额外 NuGet 依赖。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

测试已覆盖资源、兵力和经验、军官技能点、物品与单位目录加载、物品新增/数量、空槽复用、未知字段、精度、BOM 备份、覆盖与另存、撤销、外部修改冲突、版本检查，以及真实 WinForms 单元格编辑。

**验证边界：本机现有 8 个真实存档均为版本 5，按需求全部拒绝。版本 10 的验证使用合成测试夹具；尚未取得新版真实战役存档，未进行游戏内回读验证。测试文件不是可游玩的战役，不要放入实际游戏存档目录。**
